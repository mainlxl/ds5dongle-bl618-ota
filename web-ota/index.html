首次使用 / 需要先刷机？

原作者固件首次接入 OTA 前，请先刷入我们的完整固件。

如果设备当前还是原作者固件，或网页提示无法进入 OTA 接收状态，请先下载完整刷机包，通过 UART/ISP 刷入一次；之后即可直接使用下面的在线 OTA。

下载 Full-Speed 完整刷机包 正在读取最新版本... 下载 High-Speed 完整刷机包 正在读取最新版本...
  1. 按住开发板 BOOT 键，再通过 USB-C 接入电脑，保持按住直到进入 UART/ISP 下载模式。
  2. 打开 Bouffalo Lab Dev Cube，选择芯片 BL616 和 ISP（UART） 模式。
  3. 解压刷机包，选择串口，加载 `_nosec` 分区表、`boot2` 文件和对应的 `.bin` 固件，然后开始下载。
  4. 刷机完成后重新连接设备，再回到本页选择目标 OTA 版本。
